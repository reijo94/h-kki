# Akun kotiympäristön tietoturvakatsaus

## A1) Mitä sisältyy

**Kodin verkkolaitteet:**
- Modeemi: DNA Mesh WiFi F-3890
- WiFi Suojaus:, WPA2-secured, salasana Apple Passwords sovelluksessa
- MacBook Pro, iPhone

**Kurssilla käytettävät laitteet:**
- MacBook Pro 14" M4, macOS Tahoe 26.5.2
  - Viimeisin päivitys: Automaattisesti julkaisun yhteydessä
- iPhone/iPad, iOS 27 Beta — Apple Passwords + Microsoft Authenticator
- Lenovo ThinkPad juuri nyt matkalla, johon tarkoitus dualbootata Linux WIN11 rinnalle. 

**Data:**
- Kurssimateriaalit: OneDrive / paikallinen SSD
- Repo: https://github.com/reijo94/h-kki
- Salasanat: Apple Passwords sovellus + Microsoft Authenticator
- Varmuuskopiot: iCloud + OneDrive

## A2) Mitä ei sisälly

| Item | Reason |
|---|---|
| Operaattorin modeemin firmware | Toimivaltani ulkopuolella, operaattori hallinnoi |
| Perheen muut laitteet | Näitä en omista enkä käytä |
| Julkinen WiFi, Projektori (Google TV), pelikonsolit | Ei käytössä kurssilla |
